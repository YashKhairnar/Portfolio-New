# Yash Khairnar - Work Index

A minimal, text-first portfolio for an MSCS student: selected work, case studies, notes, experience, and contact.

### Deployment

Access at https://yashkhairnar.com

### Reference links

To see which shared portfolio link was opened, append `/ref/<reference>` to the
site URL. For example:

- `https://yashkhairnar.com/ref/linkedin`
- `https://yashkhairnar.com/ref/jane-doe`
- `https://yashkhairnar.com/ref/acme_recruiter`

Opening one of these links records a `portfolio_ref_visit` custom event in
Vercel Analytics with a `reference` property. Reference values may contain
lowercase letters, numbers, hyphens, and underscores, up to 64 characters.

Reference links indicate which link was opened, not a visitor's verified
identity. Use a unique reference for each recipient if you want recipient-level
attribution, and avoid putting sensitive information in the URL.
